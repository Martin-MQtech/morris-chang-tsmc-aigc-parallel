# 下册项目执行手册（L1）

> 本手册为张忠谋自传下册（1964-2018）的全局 SOP。所有章节的 L2 手册继承本文件规则。
> 上册全局规则见根目录 `执行手册.md`；下册独立运行，素材与方法复用上册已验证管线。

- 页码范围：PDF 第 33-529 页（正文约 544 页）

- 素材源：`原始素材/下册_1964-2018/章节提取/` — 45 个已切分 Markdown 文件（繁体 OCR）
- 净字符数：约 21 万
- 顶层工作区：`下册项目工作区/`

## 3. 交付标准（黄金标准，继承上册 golden-v1）

### 3.1 内容
- 中英双语严格 1:1 交替（`strict_zh_then_en`）
- OCR 精校：修正 OCR 错误、统一译名、通顺语句
- 二创 rebook-card：关键段落双语对照卡片
- 小节标题基线：基于原书文本层核实，不得自创

### 3.2 排版
- 全景目录导航：header 左侧 ☰ 目录，含全册章节索引
- 顶栏：左 ☰ 目录 / 中标题 / 右 ReadShift · 私人书房
- 底部：↑ 顶部
- 原生 JS 导航，禁止外部 CDN
- 中英文标题格式：中文标题 | 英文翻译（同行）

### 3.3 验收
- QA v3.1 fixtures 全绿
- 桌面 + 移动浏览器验收
- 控制台错误 = 0
- 每章交付一个 canonical HTML

## 4. 工作流（顺序单线程）

1. 每章先建 L2 手册（章节身份 + 页码范围 + 标题基线 + 局部事实）
2. OCR 精校 + 中英双语编辑（在 source/ 中完成）
3. 渲染 HTML（复用 render_html_v9.js）
4. QA 自测 + 浏览器验收
5. L2 手册记录验收证据
6. 进入下一章
