# 下册项目执行手册（L1 · 全局 SOP）

> 本手册为张忠谋自传下册（1964-2018）的全局标准操作程序。全部 45 章的 L2 手册继承本文件规则。
> .renderer 复用上册已验证的 `render_html_v9.js`，模板复用 `src/templates/template.ejs`。
> .翻译执行模型：**AGNES**（低成本/免费模型，但英文输出质量极高，擅长传记商业文体）。由外部协作者在新加坡调用。

- 章节数：45（含出版者的话、自序、词汇、德仪篇 13 章 + 卷首、台积电篇一/二/三共 20 章 + 3 卷首、附录 5 章）

- 执行手册制定依据：第一章（chap-01）已验收样本

## 1. 语言规范（⭐ 硬性要求）

### 1.1 简体中文（绝对强制）

**全部正文内容必须使用简体中文。** 禁止出现繁体字。

- 适用范围：标题、正文、二创卡片（Cheat Sheet · 修辞赏析 · 背景知识延伸）、导航、页脚
- 转换标准：使用 OpenCC `tw2s`（台湾繁体 → 中国大陆简体）
- 转换范围：全量 output.html 渲染成品（不是只转 source）
- 验证方法：每章渲染后，用 OpenCC 全量扫描 output.html，确认差异数为 0

### 1.2 英文翻译

英文部分必须满足：

- **质量**：地道商业/文学英语，避免 Chinglish
- **风格**：与中文原文语义对应（非逐字直译），保持阅读流畅
- **专有名词**：人名统一用英文习惯（如 Morris Chang、Stanford、Hemingway），公司名原文保留（TI、TSMC、Intel）
- **斜体**：英文标题和部分强调文字使用 `<em>` 渲染为斜体（由 CSS `font-style: italic` 控制）
- **大小写**：英文标题使用 Title Case（除介词、冠词外首字母大写）

### 1.3 双语比例

- **正文**：严格 1:1 交替（中文段落 → 英文翻译），不允许连续两段英文、不允许连续两段中文
- **二创卡片**（Cheat Sheet / 修辞赏析 / 背景知识延伸）：英文术语 + 中文解释 + 英文商业造句
- **小节标题**：中文 + 英文翻译同行显示（由 renderer 自动处理）

## 4. 内容结构规范

每个源文件（`page_XXX.md`）必须按以下结构编写，renderer 按此结构渲染：

### 4.1 正文双语段落

```markdown
<中文段落文本>

<div class="rebook-translation">
<span class="rebook-translation__label">ReadShift 双语翻译</span>
<p class="en-para">English translation paragraph here.</p>
</div>
```

**规则**：
- 中文段落在上，英文翻译在下
- 英文必须用 `<div class="rebook-translation">` 包裹
- 英文段落用 `<p class="en-para">` 标记
- 每段严格 1:1 对应（一段中文对应一段英文）

### 4.2 Cheat Sheet · 商业语汇

```markdown
### Cheat Sheet · 商业语汇

1. **Author's Preface**
**中文解释**：自序，指作者本人为本书撰写的序言，区别于他人撰写的推荐序或出版者的话。
**商业造句**：*In the author's prefac, she explains why she chose to tell the story through decisions rather than chronology.*
```

**规则**：
- 标题固定为 `### Cheat Sheet · 商业语汇`
- 格式：编号列表 + **英文术语** + **中文解释** + **商业造句**
- 英文术语保持原文（英文），中文解释使用简体中文
- 商业造句必须使用英文，斜体印刷
- 每章 3-5 条核心商业词汇

### 4.3 修辞赏析

```markdown
### 修辞赏析

<span class="rhetoric-note">
<span class="zh">中文原文分析段落</span>
<span class="en">English analysis paragraph</span>
</span>
```

**规则**：
- 标题固定为 `### 修辞赏析`
- 每则修辞分析包含原文中文分析（zh）和英文翻译（en）
- 用 `<span class="rhetoric-note">` 包裹双语对
- 用 `<span class="zh">` 和 `<span class="en">` 区分语言

### 4.4 背景知识延伸

```markdown
### 背景知识延伸

**背景知识标题**：简体中文内容，解释历史背景、人物关系、产业知识等。

**第二条知识**：更多背景内容。
```

**规则**：
- 标题固定为 `### 背景知识延伸`
- 全部使用简体中文（不需要英文翻译）
- 包含历史背景、产业知识、人物关系等补充信息
- 每章 1-3 条背景知识

## 7. 二创卡片规范

### 7.1 Cheat Sheet · 商业语汇

- **位置**：正文后第一个卡片
- **功能**：提取 3-5 条核心商业/产业词汇
- **内容**：英文术语 — 中文释义 — 英文商业造句
- **样式**：紧凑网格（术语 + 释义同行）
- **字体**：英文 Georgia 斜体 / 中文楷体 斜体
- **量控**：每章 3-5 条，不堆叠

### 7.2 修辞赏析 · Language & Logic Appreciation

- **位置**：Cheat Sheet 之后
- **功能**：分析原文修辞手法、叙事技巧
- **内容**：中文分析 + 英文翻译
- **样式**：独立卡片，内嵌 `<span class="rhetoric-note">` 双语对
- **修辞范围**：遣词、句式、韵律、结构、叙事视角

### 7.3 背景知识延伸 · Beyond the Text

- **位置**：修辞赏析之后
- **功能**：补充历史、产业、人物关系等背景知识
- **内容**：仅简体中文（不附英文翻译）
- **样式**：独立卡片，Markdown 富文本渲染

## 10. 工作流（顺序单线程）

1. **建 L2 手册**：每章先建 `chap-XX/执行手册.md`（章节身份 + 页码范围 + 标题基线 + 局部事实）
2. **编辑源文件**：在 `source/page_XXX.md` 中完成 OCR 精校 + 中英双语编辑（中文在上，英文用 `<div class="rebook-translation">` 包裹）
3. **写 Cheat Sheet**：每章提取 3-5 条商业语汇
4. **写修辞赏析**：每章 1-2 则修辞分析
5. **写背景知识延伸**：每章 1-3 条背景知识
6. **渲染 HTML**：`node render_html_v9.js --chapter N`
7. **繁简转换**：用 OpenCC 全量检测 output.html，差异必须为 0
8. **QA 自测**：检查 zh/en 配对、卡片齐全、无繁体
9. **浏览器验收**：桌面 + 移动端
10. **L2 手册记录验收证据**
11. **进入下一章**
